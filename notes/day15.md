# Day 15 学习日报

日期：2026-10-15

## 我今天学会了
1. **部署决策课**：公网 demo 的 API Key = 挂在公网的钱包，任何人玩你的 demo 都在烧你的钱——访问控制不是可选项，是账单的保险丝。选定 A+C 组合：GIF 打门面 + 面试现场本地跑做压轴（"我现场给你跑一下"在面试里的杀伤力 > 任何链接）
2. **通道思维排障**：winget 装工具超时（安装包托管在 GitHub，网络同源连不通）→ 换已验证能通的通道：pip 装 imageio-ffmpeg（自带静态 ffmpeg）。**一条路堵死时，先想你手里哪些通道是通的**
3. **GIF 压缩实战**：36.4MB → 1.4MB（-97%）。palette 两遍法（palettegen+paletteuse）+ fps/缩放；暗色终端界面对 GIF 压缩意外友好（大面积纯色）
4. **README 数据区宪法**：只放测量结果，功能描述回特性区——混一句广告进数据区，整区公信力降一档；条目重复也是病（新旧撞车）
5. **行为方差（评测方差的行为版）**：同样的"记住我"，昨天果断写盘、今天礼貌请示——模型决策风格在采样中漂移。解法正统且便宜：**期望行为写进 SYSTEM_PROMPT**（它犹豫的是"没被授权"，那就明说）。行为稳定三板斧：提示词收紧 > 采样参数 > 微调，成本从低到高
6. **幻觉持久化（本周最重的一课）**：Agent 写档案时幻觉了"2025 年"，从此每次检索都"如实"复读这个谎言——**检索增强不审写入内容的真伪，谎言进了数据库就成了档案**。比幻觉说出口危险一个量级：口误随风过，档案代代传
7. **运行时注入动态信息**：`date.today()` 拼进 SYSTEM_PROMPT——宪法保持静态，日期这种会过时的信息每次启动注入。LLM 的"今年"永远停在训练截止，不查工具就写日期必错
8. **技术博客写作**：七节故事线（钩子→预期→打破→更高期待→双重反转→修复→升维）是英雄之旅变体，文章心脏是"预期被打破的那个点"；写得具体 > 写得漂亮（"愣了三秒"胜过"深感震撼"）；ghostwriter 模式：初稿我写、真感受他补、二稿磨
9. **平台常识**：掘金 spost=草稿/预览链接（仅自己可见），post=公开链接；B 站标题公式=数字+反差+悬念，"大学生""手搓"是技术区流量词
10. **作品集三循环**：GitHub（能跑的仓库）↔ 掘金（能读的故事）↔ B 站（能看的视频）互相导流——求职作品的流量基建
